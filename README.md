# My Zen Compat

Compatibility fixes for Zen Browser mods.

## Supported combinations

### Macaron + Sidebar Expand on Hover

Compatibility improvements for:

- Tab and New Tab button outlines in the collapsed sidebar
- Media controls borders and shadows
- Webview borders and shadows during sidebar expansion
- Left and right sidebar layouts
- Right-side split view

### Macaron top bar

Additional spacing for the navigation bar in multiple-toolbar mode:

- Top: 2px
- Bottom: 8px

Single-toolbar mode is unaffected.

## Installation

Install this repository as a custom mod through Sine.

## Preferences

Both compatibility groups can be enabled or disabled independently.
